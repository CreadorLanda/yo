# ❓ FAQ

**What is ZwoSocial?**
Open-source, customizable, privacy-focused messenger.

**Is it free?**
Yes, completely open-source and free.

**Platforms?**
Android, iOS, Web, Desktop.

**E2E Encryption?**
Yes. The current implementation uses a custom client-side
X25519/TweetNaCl design. It is not the Signal Protocol or Double Ratchet and
remains subject to cryptographic audit.
